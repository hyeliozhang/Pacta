# Claims to Evidence Map

This file maps the manuscript's strongest claims to reproducible artifact evidence. It is intentionally separate from the paper so each claim can be checked directly against source files, result tables, and scripts.

| Manuscript claim | Evidence in package | What to check |
|---|---|---|
| Pacta compact certificates are efficient in the full-baseline matrix: 31.4 KiB median size, 3.64 ms generation, and 1.98 ms verification | `results/scheme_medians.csv`; `tools/results_consistency.py`; Table V in `main.tex` | Run `bash run_ci.sh`; the numeric guard recomputes the 31.4 KiB anchor from CSVs and fails on drift. |
| Compactness alone is not correctness | `results/detection.csv`; `prototype/pacta_core/optimizer.py`; `tests/test_optimizer_properties.py` | Provenance-only and policy-oblivious cases are intentionally present as negative controls. |
| The optimizer exposes a 59x legality frontier between sound compact summaries and opened evidence | `results/planner_frontier_medians.csv`; `results/optimizer_trace.csv`; `figs/planner_legality_frontier.pdf`; `tools/results_consistency.py` | Check that the compact plan is selected for ordinary governed group-by and rejected for unsummarized row predicates. |
| Range-boundary relabeling is rejected by descriptor binding | `results/detection.csv`; `prototype/pacta.py`; adversarial mutation path in `pacta.run_tests()` | The range-boundary relabeling negative control mutates interval metadata and must fail verification. |
| The typed SQL contract fails closed | `prototype/pacta_core/contract_ir.py`; `tests/test_contract_ir.py`; `tools/obligation_coverage_audit.py` | Missing bounds, None-like request fields, unknown fields, ambiguous numeric parameters, extra HAVING predicates, known-but-incompatible operator fields, unsupported aggregates, weak open scans, unbound returned-pair join segments, and incomplete many-to-many policy contracts are rejected. |
| Join, anti-join, and many-to-many contracts bind dimension predicates and tag-side policy | `prototype/pacta_core/contract_ir.py`; `prototype/pacta_core/optimizer.py`; `tests/test_contract_ir.py`; `results/join_complete.csv`; `results/join_antijoin.csv`; `results/join_many_to_many.csv` | The obligation vocabulary includes dimension-predicate binding plus request-bound scalar filters for returned-pair joins, dimension-predicate binding for FK and anti-join contracts, and dimension-policy binding for M:N joins. |
| SQLite semantic oracles independently check governed answers | `pacta.run_tests()`; `prototype/pacta.py` | Quick CI performs 240 randomized SQLite semantic cross-checks across five synthetic profiles plus two public CSV profile loads. |
| The authenticated prefix-cube materialized-view baseline is stronger than a straw man | `prototype/pacta_core/prefix_cube.py`; `results/prefix_cube_medians.csv`; `figs/physical_design_frontier.pdf` | The 50K prefix cube gives 22.5 KiB proofs and 2.89 ms verification, a 1.14 s view build, and expected-root verification while exposing update trade-offs. |
| The efficiency/scalability suite reaches the large-scale trend reported in the abstract | `prototype/pacta_core/page_index.py`; `results/large_scale_page_medians.csv`; `figs/large_scale_page_index.pdf` | The 1M-row page-cube certificate verifies in 84.83 ms and uses 489 authenticated pages; the 50K compact stress path verifies in 5.96 ms and the 100K star-prefix profile verifies in 1.34 ms. |
| Main text and artifacts stay synchronized | `tools/results_consistency.py`; `tools/submission_preflight.py`; `tools/paper_audit.py`; `tools/layout_audit.py`; `tools/obligation_coverage_audit.py` | These checks cover numbers, citations, fonts/PDF shape, page boundary, page-12 fill, structure, evidence docs, and IR/optimizer vocabulary alignment. |

The verifier scope is encoded by typed contracts and fail-closed checks rather than by informal assumptions; unsupported requests do not receive compact certificates unless their obligations are explicitly implemented.
